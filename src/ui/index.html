How the AI Investigator Works

Autonomous multi-agent collaboration for cyber threat detection, correlation, and response.

Hierarchical Multi-Agent Investigation Flow

INPUT DATA Security Telemetry CSV • JSON • Syslog • CEF
↓
PREPROCESSING & BASELINING Universal Parser & Adaptive Baseline Profiler Extracts event schema • Builds dynamic entity baselines
↓
SPECIALIST AuthenticationAgent Logon bursts • NTLM • Lateral mappings
SPECIALIST ProcessAgent LOLBins • Encoded cmd • Privilege tools
SPECIALIST NetworkAgent DGA DNS entropy • Exfiltration bursts
↓
CORRELATION CorrelationAgent Cross-Domain Temporal Graph Clustering (±10 min window)
↓
RISK SCORING AnalysisAgent Transparent Risk & Confidence • Blast radius • Diagnostic uncertainty
↓
RESPONSE ADVISORY ResponseAgent & Human Review Containment playbooks • Strict Human-in-the-loop sign-off

OrchestratorAgent

System Coordinator & Workflow Dispatcher
Meta-Agent
Receives: Normalized security event streams and behavioral context.
Checks: Partitions events across specialists and tracks execution trace timing.
Produces: Orchestrated investigation trace and synthesized cross-agent telemetry.

AuthenticationAgent

Identity & Credential Velocity Specialist
Specialist
Receives: Authentication & logon events (AUTH).
Checks: Brute-force failed logon bursts, protocol downgrades (NTLM), off-hours logins, and rare lateral host-to-host pairings.
Produces: Credential anomaly flags, compromised account tags, and authentication risk weights.

ProcessAgent

Endpoint & Execution Specialist
Specialist
Receives: Process execution & command line logs (PROCESS).
Checks: Living-off-the-Land Binaries (LOLBins: powershell, certutil, whoami, psexec), base64 encoded arguments, and rapid process trees.
Produces: Execution threat flags, LOLBin attack indicators, and host suspicion metrics.

NetworkAgent

NetFlow & DNS Resolution Specialist
Specialist
Receives: NetFlow connection logs and DNS resolution records (FLOW, DNS).
Checks: Volumetric transfer bursts (data exfiltration), unusual outbound ports, and Shannon Entropy for algorithmically generated domains (DGA C2).
Produces: C2 beaconing alerts, exfiltration volume tags, and network anomaly flags.

CorrelationAgent

Temporal Graph Clustering Specialist
Specialist
Receives: Anomalies flagged by Authentication, Process, and Network agents.
Checks: Shared user/host entity overlap and temporal clustering within a sliding window (±10 minutes / 600s).
Produces: Unified multi-source Security Incidents (INC-XXXX) linking discrete events into cohesive threat chains.

AnalysisAgent

Risk, Confidence & Uncertainty Evaluator
Specialist
Receives: Correlated incidents and specialist agent findings.
Checks: Severity distributions, multi-agent corroboration weights, blast radius scope, and diagnostic telemetry gaps.
Produces: Transparent Risk Score (0-100), Transparent Confidence Score (0-100), Severity rating, and structured explanations.

ResponseAgent

Advisory Playbook & Containment Specialist
Specialist
Receives: Incident risk, severity, and impacted host/user entities.
Checks: MITRE ATT&CK mitigation playbooks and operational containment steps.
Produces: Actionable SOC response recommendations and playbooks (Strictly requiring human approval).
